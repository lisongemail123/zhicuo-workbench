# 知错 · 个人错题本工作台

一个会随学习反馈推进复习的个人错题本：**录入 → 结构化归档 → 学习与状态回写 → 报告与下一步 → A4 组卷打印**。

根据《我用 WorkBuddy 做了个会自己推进的错题本》的需求实现，采用奶油底、砖红与深可可配色。纯 HTML、CSS、原生 JavaScript，无框架、无运行时依赖。

[打开已发布的工作台](https://cuoti-study-desk-k7m3.doublecurry16.chatgpt.site)（使用获授权的账户访问）。

## 功能

- **工作台**：今日待复习、收录与掌握情况、学习节奏、最近错题和薄弱知识点。
- **三步录入**：粘贴题干、保存原题照片，核对关键词匹配的知识点候选，选择固定错因，填写答案与解析后归档。
- **错题档案**：按学科、状态、错因、关键词筛选；支持收藏、多选、批量学习、选题组卷和回收站恢复。
- **学习中心**：按错题或知识点学习，独立思考后查看解析，标记“已掌握”或“仍需复习”。
- **知识体系**：知识点前置关系、分层学习路径、知识讲解、示例与内置相似练习；可自定义并校验循环依赖。
- **学习报告**：复习趋势、八类错因分布、知识掌握度矩阵，以及截至明天到期的建议题单；可点回原题。
- **组卷打印**：到期优先、薄弱知识点优先、高频错因优先、随机抽题四种自动策略，以及手动勾选；A4 练习卷与答案页分开。
- **个人空间**：每日目标、示例数据清除，以及包含照片、知识关系和学习记录的 JSON 备份恢复。

八类固定错因：概念不清、知识遗忘、审题遗漏、计算失误、方法不当、推理不严、表达不规范、时间不足。

## 本地运行

克隆仓库并启动静态 HTTP 服务：

```bash
git clone https://github.com/lisongemail123/zhicuo-workbench.git
cd zhicuo-workbench
python3 -m http.server 4173 --directory dist
```

打开 <http://localhost:4173>。Windows 可使用 `py -m http.server 4173 --directory dist`。

也可以使用任意静态 HTTP 服务托管 `dist/`。不要直接双击 HTML 文件；应用使用 ES Modules，需要通过 HTTP 加载。无需 `npm install`，也没有构建步骤。

> `dist/` 包含本项目直接编写的前端源码，并非由未公开代码编译得到的产物。所有 HTML、CSS、JavaScript 和测试均包含在此仓库中。

## 验证

使用 Node.js 20 或更新版本：

```bash
npm run check
npm test
```

测试覆盖上海时区日期、跨年及闰日计算、复习排期、知识依赖与循环检测、四种组卷策略、掌握度统计和备份校验。

另已进行 DOM 模拟交互检查，覆盖录入、筛选选题、学习反馈、回收站和设置保存。浏览器视觉、响应式显示与实际打印分页仍需在目标浏览器中实测。

## 复习规则与统计口径

1. 新题归档默认安排 **1 天后**首次复习，也可手动调整日期。
2. 每次标记“已掌握”后，依次安排 **2、4、7 天后**复测；第四次掌握反馈后完成该轮计划。
3. 标记“仍需复习”会重置轮次，安排 **1 天后**再次复习。
4. 已掌握的题若仍有复测日期，到期时仍会进入待复习清单。
5. 当前掌握率按在册错题的当前状态计算，不等同于历史标记次数；趋势图统计每天完成的复习次数。
6. 回收站题目不计入当前掌握率和待复习清单，但保留历史学习记录，恢复后继续使用原有状态与日期。

## 数据保存与迁移

数据仅保存在当前浏览器的 `localStorage`，键名为 `zhicuo.workbench.v1`。不向服务器上传学习数据，也不跨设备自动同步。不同域名、端口或浏览器拥有各自的存储空间；清理浏览器数据会同时清除本地错题。

在“我的学习空间”中导出 JSON 备份，可在其他设备或新部署地址导入恢复。导入前会校验数据，确认后替换当前学习空间，建议先导出原有数据。

- 照片：JPG、PNG 或 WebP，单张不超过 1.5 MB。
- 备份导入：单文件不超过 8 MB；实际可存储容量取决于浏览器配额。
- 示例题目和示例学习记录可清除，用户新录入的数据与知识库保留。
- 仓库仅包含程序与演示题库，不包含浏览器中的个人错题、备份、凭据或托管账户配置。

## 当前能力边界

照片仅用于留存，**没有 OCR**；题干需手动粘贴。知识点候选由本地关键词规则匹配，具体答案和解析由用户核对填写，**没有接入大模型自动解题**。相似题来自可编辑的内置题库。

打印使用浏览器原生打印，可打印或保存 PDF。建议选择 A4 纵向、关闭浏览器页眉页脚；线下完成后回到学习中心更新掌握状态。
