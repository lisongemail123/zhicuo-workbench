# 知错 · 错题本工作台

一个会随学习反馈推进复习的个人错题本：**录入 → 结构化归档 → 学习与状态回写 → 报告与下一步 → A4 组卷打印**。

根据《我用 WorkBuddy 做了个会自己推进的错题本》的需求实现，采用奶油底、砖红与深可可配色。4.0 增加 **服务端账号、用户注册、独立个人数据、多人共享空间与管理后台**。保留手机 ChatGPT 拍照归档、云端原图、跨设备同步、OCR 和可配置大模型。前端为原生 HTML/CSS/JavaScript，服务端支持 Cloudflare Workers/D1/R2 与本地 Node.js/SQLite/文件存储。

[打开已发布的工作台](https://cuoti-study-desk-k7m3.doublecurry16.chatgpt.site) · [配置模型与 OCR](https://cuoti-study-desk-k7m3.doublecurry16.chatgpt.site/#ai)（使用获授权的账户访问）。

## 4.0.1：公式排版与模型选择修复

- 题干、答案、错题解析、学习回顾、知识点讲解和打印卷中的数学公式使用本地 KaTeX 排版，显示标准根号、上下分式、上下标与几何符号。支持 `\(...\)`、`\[...\]`、`$...$`、`$$...$$`，并兼容旧答案中未加分隔符的 `BE'=\sqrt{4-\sqrt7}=\frac{\sqrt{14}-\sqrt2}{2}`。编辑框保留原文，有公式时自动显示排版预览；旧错题不需要重新解题或迁移。
- 公式组件、样式和 WOFF2 字体随站点部署，不需要连接外部公式 CDN。用户文字始终按文本处理；公式渲染关闭受信任 HTML、远程资源和不安全链接，并限制展开数量。无法解析的公式保留可读原文，供继续核对。
- 打印分页按完整公式切分文本，避免原来的固定字符切分截断分式或根号。网页版与 A4 答案页采用相同排版。
- “读取模型列表”使用可直接点选的原生 `select`，兼容手机浏览器。选中模型后自动填写模型 ID，仍可手动输入；保存使用填写的 ID。已有 ID 不在返回列表中时，列表仍显示全部可选项。
- 兼容常见的 `data`、`models` 及嵌套模型列表格式，清理空项和重复项；服务商返回空列表时给出明确提示。切换服务商、协议、地址或密钥后重置选择项，过期请求不会覆盖新的配置。

## 账号、同步与共享（4.0）

- **注册与登录**：用户名（3–40 位字母、数字、点、下划线、短横线）、显示名称与至少 10 字符的密码；登录后创建独立个人空间。同一账号在其他设备登录后同步同一份数据。
- **密码存储**：每个密码独立随机盐，Web Crypto PBKDF2-SHA256（100,000 次，符合 Workers Web Crypto 迭代上限）。仅保存密码哈希；会话随机令牌只以 SHA-256 摘要入库，浏览器使用 HttpOnly、SameSite=Strict Cookie，HTTPS 下启用 Secure；会话 14 天到期。
- **账号资料与凭据**：在“账号与共享空间”更新显示名称、联系邮箱、用户名和密码；修改密码使原有密码登录会话失效。邮箱为联系资料，当前不提供邮件验证或邮件重置，忘记密码由管理员生成 30 分钟内有效的一次性重置码。
- **ChatGPT 身份绑定**：Sites 提供已验证的访问身份。已连接账号的照片保存到对应个人空间；工具也可通过 `workspace_id` 选择已加入且可写的共享空间。通过 ChatGPT 首次进入的用户，可在账号页设置用户名和密码，以后从其他设备登录同一账号。已有密码账号可以绑定尚未被其他账号占用的 ChatGPT 身份，不按未验证的联系邮箱自动合并账号。
- **多人共享**：创建家庭/班级等共享空间，通过单次、7 天有效的邀请码加入。拥有者可以调整可编辑/只读权限、移除成员、撤销未用邀请；成员可以退出。个人题目不会因创建共享空间自动对外共享，需在目标空间录入或导入。
- **权限执行**：服务端每次检查账号状态、空间成员资格与角色；只读成员不能写入，非成员不能读写或获取原图。管理员可管理账号，但后台不直接提供其他用户错题正文。前端学习缓存按“用户 + 空间”隔离，模型配置与临时 API Key 按用户隔离。
- **管理后台**：管理员可在“服务端管理后台”查看用户、空间、错题和图片统计，分页管理用户角色/启停状态、撤销密码登录会话、发放一次性密码重置码、开关注册，查看最近操作日志。停用账号会同时阻止密码和 ChatGPT 入口访问。

当前已发布的 Sites 入口仍保持 owner-private。站内注册/共享邀请与站点访问权限是两层控制：**其他成员需先获准访问站点，然后才能注册或加入共享空间**。不会为启用共享而自动公开站点、发送邮件或共享原有个人数据。

### 管理员初始化与旧数据

托管版本通过 Sites 环境变量 `ADMIN_EMAIL` 指定站点拥有者的已验证 ChatGPT 邮箱。只有平台传入的验证身份匹配时才初始化管理员；用户名注册和可编辑的联系邮箱不会获得管理权限。生产配置不进入源码。首次访问会把旧版单人云数据及原图引用迁移到此拥有者的个人空间，旧表保留，其他新用户不会继承旧数据；拥有者本机旧缓存只导入一次。

本地自部署使用 `npm run admin:create` 在交互式终端创建首位管理员，密码输入不回显。普通首位注册用户不会自动成为管理员。Node 服务不信任客户端伪造的 `oai-authenticated-user-*` 请求头；只有 Sites Worker 入口启用该平台的身份解析。独立部署需用 HTTPS 反向代理到 Node 服务，保持同源 Cookie 与请求来源检查；备份 `work/cloud/` 中的数据库与原图。应用没有内置邮件服务或第三方 OAuth 服务。

## 手机 ChatGPT：拍照 → 分析 → 自动归档

首次连接后，在手机 ChatGPT 使用“知错”应用的对话中拍照并发送题图。ChatGPT 读取照片、转写题干、生成答案和分步解析，提取学科、知识点与有依据的错因，再通过应用工具将**原图和结构化结果一起保存到云端**。工作台自动同步后即可查看，并默认安排明天首次复习。

1. 发布支持 MCP 的个人私有站点后，Sites 为站点创建应用与插件。
2. 在 ChatGPT 设置 → 插件 → 你创建的，找到“知错”并完成首次安装/连接与授权；手机与工作台使用同一获授权账户。
3. 在对话中选择或 @“知错”，发送题目照片。可在首条消息加入下面的长期使用指令。
4. 归档完成后，ChatGPT 返回归档数量、重复数量、原图保存状态和工作台链接。

```text
以后我在此对话发送的题目照片，请自动识别题干、生成参考答案和解析，按学科、知识点与有依据的错因分类，保留原图并归档到知错。无法确认的内容标记待核对，不要编造。
```

这条入口使用当前 ChatGPT 对话的识别与分析能力，不要求在工作台填写外部模型 API Key。网页上的“自动解题”仍可独立使用之前配置的外部模型。日常处理的触发点是**在使用知错的 ChatGPT 对话中发送照片**；不是后台监听手机相机。应用在手机中的可用性仍受 ChatGPT 版本、账户和客户端提供的入口影响。

每张照片可归档 1–20 道题，原图最大 12 MB，支持 JPG、PNG、WebP、HEIC/HEIF 等常见图片；原图按内容去重。临时下载 URL 不持久保存，图片写入私有文件存储。同一文件标识的调用重试不会生成重复题目，重新上传的文件可作为新批次。没有原错解证据时，错因保留为“待核对”，不会强行归入某个错误原因；模糊条件与答案也应明确标注待核对。

工作台新增“手机归档与同步”页面，可复制指令、立即同步、回看最近从 ChatGPT 归档的题目，以及处理真实的跨设备编辑冲突。

## 新增：OCR 与自动解题

- **本地 OCR**：Tesseract.js 7.0.0 在浏览器内识别中英文印刷体，无需 API Key；支持简体、繁体与英文。首次需联网下载引擎和字库，图片不上传给字库/CDN 服务。
- **视觉 OCR**：使用已配置且支持图像输入的模型识别照片，结果可编辑；适合本地 OCR 难以识别的公式或手写内容，但仍需核对原题。
- **模型配置**：支持多套服务商、API Base URL、模型 ID、图像能力和超时配置，可读取模型列表、测试连接，并分别选择默认解题模型与视觉模型。
- **两种协议**：OpenAI 兼容 Chat Completions 和 Anthropic Messages。提供 DeepSeek、通义千问、OpenAI、硅基流动、Anthropic 预设，以及自定义兼容接口。
- **自动解题**：根据题干生成参考答案、分步解析、知识点和有依据的错因建议。新题录入和已有错题均可使用。
- **一键流程**：上传照片后选择“OCR 识别”“自动解题”或“识别并解题”。可设置上传后自动识别、识别后自动解题。
- **核对后采用**：识别和解题结果先预览，可修改后填入。不会自动标记为已掌握，不改变既有复习轮次和学习记录。题目在等待期间被修改时，过期结果不会覆盖新内容。

### 如何配置

1. 打开左侧“模型与 OCR”，点击“添加模型配置”。
2. 选择服务商，核对 API Base URL，输入你自己的 API Key。
3. 点击“读取模型列表”，从“可用模型”下拉菜单选择，模型 ID 会自动填入；也可以手动填写。模型 ID 以自己的账户实际可用列表为准。
4. 如用于视觉 OCR，确认该模型确实支持图片，并勾选图像能力。
5. 可先测试连接，再保存配置，选择默认解题模型与 OCR 方式。
6. 进入“录入错题”，上传照片或粘贴题干，生成并核对答案解析后归档。已有错题可打开详情，点击“AI 解题”。

API Base URL 应填写基础路径，不必追加 `/chat/completions`。例如 DeepSeek 为 `https://api.deepseek.com`，OpenAI 为 `https://api.openai.com/v1`。百炼可按账户地域与业务空间更换地址。自定义服务需为公网 HTTPS 地址；本版本后端不连接用户电脑上的 localhost 或内网模型。

### 密钥与资料

模型配置保存在按用户隔离的本地 `zhicuo.ai.config.v1:<user_id>`，其中**不含 API Key**。Key 单独保存在当前标签页的 `sessionStorage` 中，可在设置页一键清除；不会写进 GitHub、错题备份或服务端持久存储。

调用时，浏览器通过同源 `/api/ai` 将本次 Key 与题目交给后端；后端只把该 Key 转发给用户配置的接口，不跟随重定向、不转发站点登录信息、不回显服务商原始错误。使用云端模型时，题干或照片会发送给所选服务商，并按其规则计费。本地 OCR 不调用解题 API。

## 学科与学习功能

支持数学、物理、英语、化学、生物、语文及其他学科，录入、分类筛选、OCR/AI 结果、知识体系、报告与打印共用同一学科列表。生物和语文提供基础知识点、讲解与练习；已有数据会补充这两科的新知识库，保留原有错题、学习记录和自定义讲解。


- 工作台：今日待复习、收录与掌握情况、学习节奏、最近错题与薄弱知识点。
- 三步归档：原题、结构化分析、知识路径与首次复习日一起保存。
- 错题档案：按学科、状态、错因、关键词筛选；收藏、多选、批量学习、选题组卷与回收站。
- 学习中心：按错题或知识点学习，独立思考后查看解析，标记“已掌握”或“仍需复习”。
- 知识体系：前置关系、分层路径、讲解、示例与相似练习；支持自定义并检测循环依赖。
- 学习报告：复习趋势、错因分布、掌握度矩阵与下一步题单，可回到具体错题。
- 组卷打印：到期、薄弱知识点、高频错因、随机四种自动策略，以及手动勾选；A4 练习卷与答案页分开。
- 个人空间：每日目标、示例清除与包含照片、知识关系、AI 来源和学习记录的 JSON 备份恢复。

八类固定错因：概念不清、知识遗忘、审题遗漏、计算失误、方法不当、推理不严、表达不规范、时间不足。

## 本地运行

推荐 Node.js 24.15+ LTS，或 22.22.2+ LTS。

```bash
git clone https://github.com/lisongemail123/zhicuo-workbench.git
cd zhicuo-workbench
npm ci
npm run admin:create
npm start
```

打开 <http://127.0.0.1:4173>。本地服务启动时在被 Git 忽略的 `work/cloud/` 下创建 SQLite 与原图存储，并应用本地迁移；不需要云端凭据。可用 `PORT=3000 npm start` 修改端口；Windows PowerShell 使用 `$env:PORT=3000; npm start`。

本地服务默认只监听 `127.0.0.1`，同时提供页面、账号、管理、共享、同步和 AI 网关。4.0 需要服务端运行，不能仅用 Python 静态服务器或纯静态托管运行完整工作台。

## 构建与部署

```bash
npm run build
```

生成 `dist/server/index.js`，是带有 `fetch(request)` 入口的独立 Cloudflare Worker ES Module。HTML、CSS、前端 JS、OCR 主库和 worker 被嵌入部署文件，`/api/ai` 提供模型转发。云端归档使用 Sites 管理的 D1 与 R2，无需预置平台模型 API Key。

本项目 GitHub 仓库不包含个人 Sites 身份。使用 Sites 部署时，保留或创建属于自己站点的 `.openai/hosting.json`，填写真实 `project_id`，并采用 Worker 部署配置（不设置 `static`）。声明 `d1: "DB"`、`r2: "BUCKET"` 与 `capabilities: ["mcp"]`，参考 [hosting.example.json](hosting.example.json)。部署包包括该清单、`dist/server/index.js` 与 `drizzle/` 中生成的 SQL 和元数据。Sites 应用数据库迁移，并创建或刷新站点应用。不要使用其他人的站点身份。

数据接口已接入应用账号、服务端会话与空间授权；Sites 部署额外受站点访问策略保护。本地服务仅监听回环地址，对外部署需通过 HTTPS 反向代理，不能公开数据库或原图目录。Sites 上配置 `ADMIN_EMAIL` 后再发布，才能应用管理员初始化规则。

OCR 主库及 worker 已随源码保留。若需要重新生成：

```bash
npm run vendor:ocr
npm run vendor:math
```

字库与 WASM 默认按需在线加载并缓存；依赖说明与许可证见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 复习与数据规则

新题默认 1 天后首次复习；标记掌握后依次在 2、4、7 天后复测，第四轮完成。仍需复习则重置为 1 天后。已掌握但仍有复测日期的题，到期后仍会进入清单。AI 生成不会修改这些学习状态。

当前掌握率按在册错题的状态计算，趋势图统计复习次数；回收站题目不计入当前掌握率或到期清单，但保留历史记录。没有关联错题的知识点不计入掌握率。

真实学习数据在启用云端后同步到 D1，原图保存在 R2；浏览器 `localStorage` 保留离线缓存，键名为 `zhicuo.workbench.v1:<user_id>:<workspace_id>`，兼容拥有者旧版缓存。真实错题、知识点与学习记录在对应空间内合并同步，示例题和示例学习记录不上传；旧全局键不会被用于其他用户账号。

各设备通过版本号合并更新；同一条目被同时修改时保留冲突供选择，不直接覆盖较新的云端版本。离线改动保留在本机，联网后继续同步。云端删除用版本化标记传播，永久删除最后一条引用的错题后清理对应原图。

JSON 备份保存结构化数据和云端原图引用，**不会打包云端图片本体**；同一工作台中可继续访问这些私有原图，迁移到新的部署时需另外迁移文件存储。旧版内嵌照片仍可导入。模型配置和 API Key 不进入云端学习数据。

照片支持 JPG/PNG/WebP，单张不超过 1.5 MB；备份导入不超过 8 MB，实际容量受浏览器配额限制。推荐一题一张、清晰拍摄。印刷体本地识别效果通常优于手写，复杂公式、模糊字迹和图示条件均需核对。模型也可能出错，采用前请检查答案与解析。

相似训练题仍来自可编辑的内置题库。打印使用浏览器原生打印，建议 A4 纵向、关闭页眉页脚；线下完成后回到学习中心更新掌握状态。

数据库结构变更使用 `npm run db:generate` 生成迁移。已应用的 SQL、快照与日志不可改写；后续结构调整应追加迁移。
